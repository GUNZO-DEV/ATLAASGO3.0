# Atlaasgo

A Moroccan delivery platform.

## Stack
- **Frontend:** Next.js
- **Backend/Database:** Firebase

## Rules
1. No taxi services
2. Use emerald green accents
3. Always run a browser test via Antigravity after UI changes

## Consultation Protocol
1. If a task involves complex Firebase logic or Moroccan market nuances you aren't 100% sure about, STOP.
2. Write the specific technical question into a new file called `ASK_GEMINI.md`.
3. Outline the current code state, the error, and exactly what you need to know.
4. Wait for the user to provide the response before continuing.
