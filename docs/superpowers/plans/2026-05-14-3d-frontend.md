>
> **Prerequisite:** `2026-05-14-foundation.md` must be fully complete before starting this plan. All shared 3D components (`components/3d/`) and `lib/r3f/` must exist.

**Goal:** Redesign every user-facing page with React Three Fiber 3D elements — Atlas mountains on the landing page, DeliveryOrb status on the customer dashboard, TruckModel + BarChart3D on the driver dashboard, and a birds-eye CityMap3D on admin.

**Architecture:** Each page gets a full-viewport `SceneCanvas` as a background layer (absolutely positioned, pointer-events: none) with 2D UI floating above it. Framer Motion handles scroll-driven parallax on the landing page. R3F scenes are `dynamic` imports to avoid SSR issues.

**Tech Stack:** React Three Fiber 8, @react-three/drei 9, Framer Motion 12, Next.js 16 App Router, Tailwind CSS v4, Firebase Firestore real-time listeners

## Task 3: 3D Zone Cards

**Files:**

- Modify: `app/page.tsx`

- [ ] **Step 1: Create components/3d/ZoneCard3D.tsx**

```tsx
// components/3d/ZoneCard3D.tsx
"use client";

import { useRef, useState } from "react";
import { motion, useMotionValue, useSpring, useTransform } from "framer-motion";
import type { ReactNode } from "react";

interface ZoneCard3DProps {
  children: ReactNode;
  className?: string;
}

/**
 * 3D tilt card using CSS perspective transform driven by mouse position.
 * Wraps any content. Used for the Ifrane/Oujda zone cards on landing page.
 */
export default function ZoneCard3D({ children, className = "" }: ZoneCard3DProps) {
  const ref = useRef<HTMLDivElement>(null);
  const x = useMotionValue(0);
  const y = useMotionValue(0);
  const springConfig = { stiffness: 200, damping: 20 };
  const xSpring = useSpring(x, springConfig);
  const ySpring = useSpring(y, springConfig);

  const rotateX = useTransform(ySpring, [-0.5, 0.5], ["8deg", "-8deg"]);
  const rotateY = useTransform(xSpring, [-0.5, 0.5], ["-8deg", "8deg"]);

  const handleMouseMove = (e: React.MouseEvent<HTMLDivElement>) => {
    if (!ref.current) return;
    const { left, top, width, height } = ref.current.getBoundingClientRect();
    x.set((e.clientX - left - width / 2) / width);
    y.set((e.clientY - top - height / 2) / height);
  };

  const handleMouseLeave = () => {
    x.set(0);
    y.set(0);
  };

  return (
    <motion.div
      ref={ref}
      onMouseMove={handleMouseMove}
      onMouseLeave={handleMouseLeave}
      style={{
        rotateX,
        rotateY,
        transformStyle: "preserve-3d",
        perspective: 800,
      }}
      whileHover={{ scale: 1.02 }}
      transition={{ duration: 0.15 }}
      className={className}
    >
      <div style={{ transform: "translateZ(20px)" }}>{children}</div>
    </motion.div>
  );
}
```
